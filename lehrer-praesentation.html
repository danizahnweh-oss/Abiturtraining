So funktioniert's

In drei einfachen Schritten zum digitalen Abitur-Unterricht

1

Konto erstellen

Registrieren Sie sich mit Name, Passwort und Ihren Fächern. Zugang per Registrierungsschlüssel.

2

Aufgabe erstellen

Fach und Typ wählen – die KI generiert alles. Oder eigene Materialien hochladen.

3

Code an Schüler

Schüler geben den Code auf myabiflow.de/aufgabe ein und bearbeiten die Aufgabe. Sie sehen die Ergebnisse live.

Die vier Bereiche im Detail

Klicken Sie auf einen Tab, um den Bereich zu erkunden

📄 Meine Codes

Erstellen und verwalten Sie Klassen-Codes. Jeder Code verbindet eine Klasse mit Ihrem Dashboard. Schüler geben den Code auf der Fachseite ein, um Ergebnisse automatisch zu teilen.

✨ Codes erstellen

Bezeichnung eingeben (z.B. „12a Deutsch“) und auf „Neuer Code“ klicken. Sofort einsatzbereit.

📋 Codes teilen

Per Klick kopieren und an Schüler verteilen – per Tafel, Mebis oder Ausdruck.

🛠 Codes verwalten

Schüler-Anzahl und Ergebnisse pro Code einsehen. Nicht benötigte Codes löschen.

🔌 Auto-Verknüpfung

Sobald ein Schüler den Code eingibt, erscheinen seine Ergebnisse automatisch in Ihrem Dashboard.

📝 Aufgaben

Erstellen Sie Abitur-Aufgaben – entweder per KI-Generierung oder aus eigenen Materialien. Jede Aufgabe kann bearbeitet, gespeichert und per Code geteilt werden.

🤖 KI generieren

Fach und Typ wählen → vollständige Aufgabe mit Erwartungshorizont. Vor dem Teilen anpassbar.

📎 Eigene Materialien

Bis zu 5 Bilder/PDFs hochladen. Die KI analysiert und generiert passende Aufgaben daraus.

✎ Aufgaben bearbeiten

Texte, Titel und Kriterien frei anpassen. Auch gespeicherte Aufgaben nachträglich bearbeitbar.

🔗 Code teilen

Jede Aufgabe erhält einen eigenen Code. Schüler bearbeiten sie auf myabiflow.de/aufgabe.

👥 Meine Schüler

Das Herzstück: Alle Schüler, ihre Ergebnisse und Förderbedarfe auf einen Blick. Mit interaktiver Heatmap und automatischem Warnsystem.

📈 Statistik-Übersicht

Gesamtzahl der Schüler, Durchschnitt und Ergebnisanzahl auf einen Blick.

⚠ Warnsystem

Automatische Erkennung schwacher Leistungen (unter 5 NP). Sofort sehen, wer Hilfe braucht.

🎯 Stärken & Schwächen

KI-basierte Analyse der häufigsten Stärken und Schwächen Ihrer gesamten Klasse.

🔥 Heatmap

Farbcodiert: Grün = gut, Gelb = mittel, Rot = Förderung nötig. Schnelle visuelle Orientierung.

📊 Analytics

Interaktive Diagramme für datengestützte Entscheidungen im Unterricht. Von Fachübersichten bis Leistungstrends.

📊 Fach-Übersicht

Balkendiagramm mit durchschnittlichen Notenpunkten pro Fach.

📈 Leistungsentwicklung

👤 Schüler-Detail

💬 Für Gespräche
