Was ist myAbiFlow?

myAbiFlow ist eine digitale Lernplattform fur das bayerische G9-Abitur. Der Lehrer-Bereich gibt Ihnen als Lehrkraft die Werkzeuge, um Ihren Unterricht effizienter zu gestalten.

⚡

KI-Aufgaben in Sekunden

Generieren Sie lehrplankonforme Abitur-Aufgaben per Knopfdruck. Die KI erstellt automatisch Erwartungshorizont und Bewertungskriterien.

  • Alle Abiturfacher verfugbar
  • Automatischer Erwartungshorizont
  • Verschiedene Aufgabentypen pro Fach
📋

Eigene Materialien hochladen

Laden Sie eigene Arbeitsblatter, Texte oder Bilder hoch – die KI erstellt daraus passende Aufgaben mit Bewertungskriterien.

  • 1–5 Bilder oder PDFs hochladen
  • Zusatzliche Anweisungen moglich
  • Aufgaben direkt bearbeitbar
🔗

Einfache Code-Verteilung

Schuler brauchen kein eigenes Konto. Erstellen Sie einen Klassen-Code, teilen Sie ihn – fertig. Ergebnisse fliessen automatisch in Ihr Dashboard.

  • Ein Code pro Klasse/Kurs
  • Schuler geben Code auf myabiflow.de ein
  • Kein Schuler-Account notig
📈

Schuler-Fortschritt im Blick

Sehen Sie auf einen Blick, wer gut vorbereitet ist und wer Hilfe braucht. Das automatische Warnsystem meldet schwache Leistungen fruhzeitig.

  • Notenpunkte-Ubersicht pro Schuler
  • Automatisches Warnsystem
  • Leistungsentwicklung uber Zeit
🎯

Starken- & Schwachen-Analyse

KI-gestutzte Auswertung zeigt individuelle Kompetenzlucken – damit Sie gezielt fordern statt pauschal wiederholen.

  • Starken & Schwachen pro Schuler
  • Klassen-Ubersicht aller Kompetenzen
  • Basierend auf KI-Bewertungen
📊

Analytics & Heatmaps

Interaktive Diagramme zeigen Fach-Ubersichten, Leistungstrends und eine Schuler-x-Facher-Heatmap fur schnelle Ubersicht.

  • Fach-Ubersicht (Balkendiagramm)

So funktioniert's

In drei einfachen Schritten zum digitalen Abitur-Unterricht

1

Konto erstellen

Registrieren Sie sich mit Name, Passwort und Ihren Fachern. Sie erhalten einen Zugang per Registrierungsschlussel.

→
2

Aufgabe erstellen

Wahlen Sie Fach und Aufgabentyp. Die KI generiert die Aufgabe – oder Sie laden eigene Materialien hoch.

→
3

Code an Schuler geben

Schuler geben den Code auf myabiflow.de/aufgabe ein, bearbeiten die Aufgabe – und Sie sehen die Ergebnisse live.

Die vier Bereiche im Detail

Nach dem Login stehen Ihnen vier Tabs zur Verfugung

1

Meine Codes

Erstellen und verwalten Sie Klassen-Codes. Jeder Code verbindet eine Klasse oder einen Kurs mit Ihrem Dashboard. Schuler geben den Code auf der jeweiligen Fachseite ein, um ihre Ergebnisse automatisch mit Ihnen zu teilen.

Codes erstellen

Geben Sie eine Bezeichnung ein (z.B. „12a Deutsch“) und klicken Sie auf „Neuer Code“. Der Code wird sofort generiert.

Codes teilen

Kopieren Sie den Code per Klick und teilen Sie ihn mit Ihren Schulern – per Tafel, Mebis oder Ausdruck.

Codes verwalten

Sehen Sie auf einen Blick, wie viele Schuler und Ergebnisse pro Code vorhanden sind. Nicht mehr benotigte Codes loschen.

Automatische Verknupfung

Sobald ein Schuler den Code eingibt, erscheinen seine Ergebnisse automatisch in Ihrem Schuler-Tab.

2

Aufgaben

Erstellen Sie Abitur-Aufgaben fur Ihre Schuler – entweder per KI-Generierung oder aus eigenen Materialien. Jede Aufgabe kann bearbeitet, gespeichert und per Code geteilt werden.

KI generieren

Fach und Aufgabentyp wahlen → die KI erstellt eine vollstandige Aufgabe mit Erwartungshorizont. Sie konnen alles vor dem Teilen anpassen.

Eigene Materialien

Laden Sie bis zu 5 Bilder/PDFs hoch. Die KI analysiert Ihre Materialien und generiert passende Aufgaben daraus.

Aufgaben bearbeiten

Texte, Titel und Bewertungskriterien konnen vor dem Speichern frei angepasst werden. Auch gespeicherte Aufgaben sind nachtraglich bearbeitbar.

Aufgaben-Code teilen

Jede gespeicherte Aufgabe erhalt einen eigenen Code. Schuler geben ihn auf myabiflow.de/aufgabe ein und bearbeiten die Aufgabe.

3

Meine Schuler

Das Herzstuck des Lehrer-Bereichs: Sehen Sie alle Schuler, ihre Ergebnisse und erkennen Sie Forderbedarfe auf einen Blick.

Statistik-Ubersicht

Gesamtzahl der Schuler, durchschnittliche Notenpunkte und Anzahl der Ergebnisse – auf einen Blick.

Warnsystem

Automatische Erkennung von Schulern mit schwachen Leistungen (unter 5 NP). Sie sehen sofort, wer besondere Aufmerksamkeit braucht.

Starken & Schwachen

KI-basierte Analyse zeigt die haufigsten Starken und Schwachen Ihrer gesamten Klasse – ideal fur gezielte Wiederholung.

Heatmap: Schuler x Facher

Farbcodierte Ubersicht: Grun = gut, Gelb = mittel, Rot = Forderung notig. Schnelle visuelle Orientierung.

4

Analytics

Interaktive Diagramme fur datengestutzte Entscheidungen im Unterricht.

Fach-Ubersicht

Balkendiagramm zeigt die durchschnittlichen Notenpunkte pro Fach. Erkennen Sie auf einen Blick, wo Ihre Schuler stehen.

Leistungsentwicklung

Liniendiagramm zeigt den Verlauf der Notenpunkte uber die Zeit – getrennt nach Fachern. Trends fruhzeitig erkennen.

Schuler-Detail

Klicken Sie auf einen Schuler fur eine individuelle Detailansicht mit personlichem Leistungsverlauf und Fach-Aufschlusselung.

Datenexport

Alle Daten sind jederzeit einsehbar und konnen fur Elterngesprache oder Konferenzen genutzt werden.
