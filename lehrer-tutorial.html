🔐 Registrierung & Login

✍ So registrieren Sie sich

Um den Lehrer-Bereich nutzen zu können, benötigen Sie ein Lehrer-Konto. Die Registrierung ist in wenigen Sekunden erledigt.

  1. Öffnen Sie myabiflow.de/lehrer in Ihrem Browser
  2. Klicken Sie auf „Registrieren“ (Umschalter oben)
  3. Geben Sie Ihren Namen und ein Passwort ein
  4. Tragen Sie Ihre E-Mail-Adresse ein
  5. Wählen Sie Ihre Fächer aus (mindestens eines)
  6. Klicken Sie auf „Registrieren“
🔒 Für die Aktivierung Ihres Kontos kontaktieren Sie info@myabiflow.de. Sie erhalten einen Registrierungsschlüssel, den Ihre Schule von uns bekommt.

🔑 So loggen Sie sich ein

Nach der Registrierung können Sie sich jederzeit einloggen:

  1. Öffnen Sie myabiflow.de/lehrer
  2. Geben Sie Ihren Namen und Ihr Passwort ein
  3. Klicken Sie auf „Anmelden“
💡 Ihr Login bleibt gespeichert, solange Sie den Browser nicht schließen. Sie müssen sich nicht bei jedem Besuch neu anmelden.

📄 Meine Codes verwalten

💡 Was sind Codes?

Codes sind der Schlüssel, mit dem Sie Ihre Schüler mit Ihrem Dashboard verbinden. Jeder Code gehört zu einer Klasse oder einem Kurs. Wenn ein Schüler den Code auf myabiflow.de eingibt, werden seine Ergebnisse automatisch in Ihrem Lehrer-Bereich angezeigt.

✨ Neuen Code erstellen

  1. Wechseln Sie zum Tab „Meine Codes“
  2. Geben Sie eine Bezeichnung ein (z.B. „12a Deutsch“ oder „Q12 Physik eA“)
  3. Klicken Sie auf „Neuer Code“
  4. Der Code wird sofort generiert und ist einsatzbereit
💡 Tipp: Erstellen Sie pro Kurs oder Klasse einen eigenen Code. So können Sie die Ergebnisse später sauber filtern.

📋 Codes an Schüler verteilen

Klicken Sie auf den Code, um ihn in die Zwischenablage zu kopieren. Dann können Sie ihn per Tafel, Mebis, E-Mail oder Ausdruck an Ihre Schüler weitergeben.

Ihre Schüler geben den Code dann auf der jeweiligen Fachseite (z.B. myabiflow.de/deutsch) unter „Lehrer-Code eingeben“ ein.

🛠 Codes verwalten

In der Code-Übersicht sehen Sie für jeden Code:

  1. Bezeichnung – der Name, den Sie vergeben haben
  2. Status – aktiv (grün) oder inaktiv (rot)
  3. Erstellt am – wann der Code angelegt wurde
  4. Per Klick können Sie Codes aktivieren/deaktivieren oder löschen
⚠ Ein deaktivierter Code kann von Schülern nicht mehr verwendet werden. Die bisherigen Ergebnisse bleiben aber erhalten.

📝 Aufgaben erstellen

💡 Zwei Wege zur Aufgabe

Im Tab „Aufgaben“ haben Sie zwei Möglichkeiten, Aufgaben zu erstellen:

  1. KI-Generierung – Die KI erstellt eine komplette Aufgabe mit Erwartungshorizont
  2. Eigene Materialien – Laden Sie Bilder oder PDFs hoch, die KI erstellt daraus Aufgaben

🤖 Weg 1: KI-Aufgabe generieren

  1. Wechseln Sie zum Tab „Aufgaben“
  2. Wählen Sie ein Fach aus (z.B. Deutsch, Mathematik, Geschichte…)
  3. Wählen Sie den Aufgabentyp (z.B. Erörterung, Analyse, Textvergleich…)
  4. Klicken Sie auf „Aufgabe generieren“
  5. Die KI erstellt die Aufgabe inklusive Erwartungshorizont und Bewertungskriterien
  6. Prüfen und bearbeiten Sie die Aufgabe bei Bedarf
  7. Klicken Sie auf „Aufgabe speichern“
💡 Alle generierten Aufgaben sind an den LehrplanPLUS Bayern G9 angepasst. Sie können den Text aber jederzeit anpassen.

📎 Weg 2: Eigene Materialien hochladen

  1. Wählen Sie „Eigene Materialien“ als Modus
  2. Ziehen Sie Dateien in die Upload-Zone (oder klicken Sie zum Auswählen)
  3. Erlaubt: Bilder (JPG, PNG) und PDFs – max. 10 MB pro Datei
  4. Bis zu 5 Materialien gleichzeitig
  5. Optional: Geben Sie zusätzliche Anweisungen ein (z.B. „Erstelle Aufgaben zum Thema Expressionismus“)
  6. Klicken Sie auf „Aufgabe erstellen“

🔗 Aufgabe teilen

Nach dem Speichern erhält jede Aufgabe einen eigenen Code. Diesen Code geben Sie an Ihre Schüler weiter:

  1. Der Aufgaben-Code wird automatisch angezeigt
  2. Klicken Sie auf den Code, um ihn zu kopieren
  3. Schüler öffnen myabiflow.de/aufgabe und geben den Code ein
  4. Die Schüler bearbeiten die Aufgabe – Ergebnisse landen automatisch in Ihrem Dashboard
📚 Sie können beliebig viele Aufgaben erstellen und jederzeit neue generieren.

👥 Meine Schüler

📈 Die Schüler-Übersicht

Im Tab „Meine Schüler“ sehen Sie alle Schüler, die Ihren Code eingegeben haben. Für jeden Schüler gibt es eine Karte mit:

  1. Versuche – Wie viele Aufgaben der Schüler bearbeitet hat
  2. Durchschnitt (Ø) – Mittlere Notenpunkte über alle Versuche
  3. Beste Leistung – Höchste erreichte Punktzahl
  4. Trend – Pfeil nach oben (📈) oder unten (📉) je nach Entwicklung

🔍 Schüler-Detailansicht

Klicken Sie auf einen Schüler, um die Detailansicht zu öffnen:

  1. Persönliche Statistiken – Versuche, Durchschnitt, Beste Leistung, Trend
  2. Fach-Grid – Ergebnisse aufgeschlüsselt nach Fächern
  3. Detaillierte Scores – Inhalt, Sprache und Gesamt pro Versuch
  4. Stärken & Schwächen – KI-basierte Analyse der Kompetenzen
💡 Die Detailansicht eignet sich hervorragend für Elterngespräche – Sie können die Entwicklung des Schülers anhand konkreter Daten zeigen.

⚠ Automatisches Warnsystem

Das Warnsystem erkennt automatisch Schüler mit Förderbedarf:

  1. Rot – Schüler mit einem Durchschnitt unter 5 Notenpunkten
  2. Gelb – Schüler mit abfallendem Trend (Verschlechterung)
⚠ Warnungen erscheinen automatisch oben im Tab. So verpassen Sie keinen Förderbedarf.

📊 Analytics & Heatmaps

📈 Fach-Übersicht

Das Balkendiagramm zeigt die durchschnittlichen Notenpunkte pro Fach für alle Schüler. So erkennen Sie auf einen Blick, in welchen Fächern Ihre Klasse stark ist und wo Nachholbedarf besteht.

🔥 Schüler-x-Fächer Heatmap

Die interaktive Heatmap ist das mächtigste Werkzeug im Analytics-Bereich:

  1. Zeilen = Schüler, Spalten = Fächer
  2. Grün (≥ 10 NP) = gute Leistung
  3. Gelb (5–9 NP) = mittlere Leistung
  4. Rot (< 5 NP) = Förderbedarf
  5. Klicken Sie auf eine Zelle, um die Schüler-Detailansicht zu öffnen
💡 Die Heatmap eignet sich perfekt für pädagogische Konferenzen – Sie sehen sofort, welche Schüler in welchen Fächern unterstützt werden müssen.

📈 Leistungsentwicklung (Trend)

Das Liniendiagramm zeigt die Entwicklung der durchschnittlichen Notenpunkte über die Zeit, aufgeschlüsselt nach Fächern. So erkennen Sie:

  1. Ob sich die Klasse insgesamt verbessert oder verschlechtert
  2. In welchen Fächern der größte Fortschritt stattfindet
  3. Ob einzelne Fächer stagnierende Leistungen zeigen

⚙ Profil, Guthaben & mehr

👤 Profil verwalten

Klicken Sie oben rechts auf Ihren Namen, um das Profil-Overlay zu öffnen. Dort sehen Sie:

  1. Ihren Namen und Ihre E-Mail-Adresse
  2. Ihren Status (Pending = warten auf Aktivierung, Approved = freigeschaltet)
  3. Ihre ausgewählten Fächer – diese können Sie jederzeit ändern

💰 Guthaben & Korrekturen

Das Korrektur-Guthaben zeigt, wie viele KI-Korrekturen Ihnen noch zur Verfügung stehen:

  1. Der Guthaben-Balken zeigt visuell, wie viele Korrekturen übrig sind
  2. Klicken Sie auf „Verlauf anzeigen“, um zu sehen, wann welche Korrekturen verbraucht wurden
  3. Jede Aufgabe, die ein Schüler einreicht und die KI korrigiert, verbraucht eine Korrektur
💰 Ein Korrektur-Paket (75 Korrekturen für 49 €) können Sie jederzeit nachbestellen. Das sind nur 0,65 € pro Korrektur.

🌙 Dark Mode

Oben rechts finden Sie den Theme-Toggle. Per Klick wechseln Sie zwischen dem hellen und dunklen Design. Ideal für:

  1. Abgedunkelte Räume bei Beamer-Präsentationen
  2. Abends am Laptop, wenn Sie Ergebnisse prüfen
  3. Persönliche Vorliebe – Ihre Einstellung wird gespeichert

📱 Tablet-Nutzung

Der gesamte Lehrer-Bereich ist für Tablets optimiert (iPad, Android, Surface). Alle Buttons sind groß genug für Touch-Bedienung und das Layout passt sich automatisch an.

💡 Tipp: Speichern Sie myabiflow.de/lehrer als Lesezeichen auf Ihrem Tablet-Homescreen – so haben Sie den Lehrer-Bereich immer griffbereit wie eine App.
