# SEO Keyword-Recherche

Führe eine Keyword-Recherche für ein bestimmtes Thema durch.

## Argument

$ARGUMENTS — Das Thema oder Seed-Keyword (z.B. "Mathe Kolloquium Bayern", "Abitur Vorbereitung")

## Analyse-Schritte

### 1. Suchintent bestimmen
- **Informational**: User will etwas lernen/verstehen
- **Navigational**: User sucht eine bestimmte Seite
- **Transactional**: User will etwas kaufen/nutzen
- **Commercial Investigation**: User vergleicht Optionen

### 2. Keyword-Cluster erstellen
- **Haupt-Keyword**: Das zentrale Keyword mit höchstem Suchvolumen
- **Sekundäre Keywords**: Eng verwandte Begriffe
- **Long-Tail Keywords**: Spezifische 3-5 Wort Kombinationen
- **Fragen-Keywords**: "Wie", "Was", "Warum"-Formulierungen (gut für Featured Snippets)
- **LSI Keywords**: Semantisch verwandte Begriffe

### 3. Wettbewerbs-Einschätzung
- Wie schwer ist es, für dieses Keyword zu ranken?
- Welche Art von Content rankt aktuell? (Blogs, Tools, Videos)
- Gibt es Content-Lücken die myabiflow.de füllen kann?

### 4. Content-Empfehlungen
- Welcher Content-Typ passt? (Landingpage, Blog, Tool, FAQ)
- Empfohlene Seitenstruktur (H1, H2s)
- Welche Fragen sollte der Content beantworten?
- Interne Verlinkungsmöglichkeiten zu bestehenden Seiten

### 5. Zielgruppen-Kontext
- myabiflow.de richtet sich an bayerische Abiturienten (G9)
- Keywords im Bildungsbereich / Prüfungsvorbereitung
- Regionale Relevanz: Bayern, Deutschland
- Zielgruppe: Schüler 16-19 Jahre, teilweise Eltern/Lehrer
